# ARCANA 视觉重设计 —「午夜占卜室」Midnight Séance

日期：2026-09-01
范围：`/tarot/` 纯视觉层换血；流程、数据、音频、无构建架构不变。

## 设计方向

从 v1「黑底网格 · 极简科技感」→ v2「**午夜占星台 · 古典神秘主义**」。
关键词：midnight séance / celestial atelier / 旧金 × 午夜蓝 / 罗马雕刻体 / 星空与月相 / 羊皮纸牌面。

依据（ui-ux-pro-max 检索结论）：
- Luxury 体系：近黑底 + 金 accent（#CA8A04/#D4AF37）为高端定式 → 升级为渐变旧金
- 字体：Cinzel（罗马碑刻体，传统塔罗牌面用字）+ Cormorant（诗性衬线）+ Noto Serif SC（中文宋体）
- OLED 暗色准则：低强度光晕、高对比文本、`prefers-reduced-motion` 全量尊重
- 无 emoji 图标，全部 SVG 线稿；可点元素 cursor:pointer；过渡 150–300ms

## 二、背景氛围（替换 24px 网格）

1. **星空层**：JS 生成 ~120 星点（1–2px，透明度呼吸 6–9s 错峰；reduced-motion 时静态）
2. **黄道十二轮**：居中巨型 SVG（几何轮辐 + 刻度 + 星点连线），旧金 stroke，opacity .07，180s 极慢旋转
3. **星云**：2–3 组径向渐变（靛/紫），`filter: blur(60px)` 预烘焙，无 JS 动画
4. **月相 widget**：顶栏实时计算当前月相（朔望周期 29.53059d），SVG 明暗界线渲染 + 农历式文案「今夜宜问卜」
5. **胶片颗粒**：SVG feTurbulence 噪点叠加，opacity .04
6. 暗角保留（收得更深）

## 三、字体系统

| 层 | 字体 | 用途 |
|---|---|---|
| Display | **Cinzel** 400/600 | 牌名 EN、大标题、罗马数字 |
| Serif | **Cormorant** 500 italic + **Noto Serif SC** | 引言、释义、中文牌名 |
| Mono | Geist Mono（本地 woff2，沿用） | 标签、数据、小字 |

落地方式：Google Fonts CDN 引入 + `font-display:swap`；确认设计后下载 woff2 入仓（`tarot/fonts/`）保持离线可用（v1 特性不回退）。

## 四、卡牌重设计（核心）

**牌背**（白底黑线 → 午夜蓝 + 金曼陀罗）：
- 底 `--night-2`，金细线双框 + 四角花体刻饰
- 中央 sacred-geometry 曼陀罗：同心圆 + 8 芒星 + 月相弧（八个月相小圆）
- 底部走马灯改为金色小字「✦ the cards know ✦ 牌知晓一切」

**牌面**（纯白 → 羊皮纸 + 金墨双色）：
- 底 `--parchment` + 老化径向渐变 + 噪点
- 双线框 + 角部 L 形刻饰（金）
- 罗马数字（Cinzel）置于角标；徽记线稿墨黑 + 关键笔画金渐变 + 星芒晕
- 中文名 Noto Serif SC + 英文名 Cinzel 字距展开
- 逆位：内容旋转 180°（保留）+ 角标加「✦」金点提示

## 五、组件升级

- **仪式问题框**：金角刻线相框式 textarea，placeholder「静心 · 默念你的问题」
- **牌阵按钮**：金细边 + 角刻线，hover 金光内渗（无 scale，避免布局位移）
- **解读面板**：`--night-2` 底 + 金分隔饰线（`✦ — ✦ — ✦`），条目头加四元素小徽（火△/水▽/风◯/土□，SVG）
- **翻牌动效**：翻面瞬间金色微光 flash（120ms）；牌 hover 金边光晕
- **页脚**：黄道轮缩小 + 「As above, so below · 如在其上，如在其下」

## 六、不变项

三场景流程、22 张数据与释义、正逆位逻辑、扇形交互（含命中条方案）、全部音效、静音持久化、`server.mjs`、零构建。

## 七、可访问性

- 金/月光文本对 `--night-1` 对比 ≥ 4.5:1（gold-2 ≈7:1, silver ≈9:1）
- 星空呼吸/黄道轮旋转全部包裹 `prefers-reduced-motion: reduce`
- 动效仅光晕/透明度，不用位移缩放引起布局跳动
